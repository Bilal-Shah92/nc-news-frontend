# NC News Frontend

This is the frontend for my NC News project.
Users can browse articles, sort by different criteria, view single articles, read comments, post comments, and delete their own comments.  
This app was built with React + Vite as part of the Northcoders Software Engineering Bootcamp.

---

## Live Deployed Version

Frontend: **https://peaceful-boba-8ba5d2.netlify.app/**  
Backend API: **https://be-nc-news-3exq.onrender.com/api**
Backend Github: **https://github.com/Bilal-Shah92/be-nc-news**

---

## Features

- View all the articles  
- Filter articles by topic  
- Sort by date, votes, or comment count  
- Toggle ascending/descending order  
- View a full article page  
- Post a comment as a logged-in user  
- Delete your own comments  
- Client-side routing with fully working refresh (Netlify redirects included)  
- Dedicated 404 Not Found page  
- Fully responsive layout
